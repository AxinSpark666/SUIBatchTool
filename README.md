# SUI Batch Transfer Pro (SUI 批量转账工具)

一个纯前端、安全、高效的 SUI 区块链批量转账与归集工具。支持多对多转账、批量归集、批量分发等多种模式，专为 SUI 生态用户设计。

## 🛡️ 安全声明

*   **纯本地运行**：本工具是一个纯 HTML/JS 单页应用。
*   **零服务器交互**：所有私钥签名操作均在您的浏览器本地完成，**绝不会**将私钥发送到任何外部服务器。
*   **开源透明**：您可以直接右键查看源代码，或断网运行（加载完 SDK 后）。

## ✨ 核心功能

### 1. 三种转账模式
*   **多对多 (M:N)**：第 1 个私钥转给第 1 个地址，第 2 个转给第 2 个... 适合空投交互或点对点转移。
*   **批量归集 (M:1)**：将多个钱包的资金汇总到一个主钱包。
*   **批量分发 (1:N)**：从一个主钱包向多个地址批量发送资金。

### 2. 灵活的金额设置
*   **固定金额**：发送指定数量。
*   **全部余额**：自动计算 Gas 费并发送所有可用余额（扫地模式）。
*   **百分比**：发送余额的指定百分比（例如 50%）。
*   **随机金额**：在设定的最小值和最大值之间随机生成金额，适合防女巫交互。

### 3. 智能网络控制
*   **RPC 智能管理**：
    *   内置 Chainstack (默认) 和 SUI 官方节点。
    *   支持自定义 RPC 节点地址。
    *   实时检测 RPC 连通性与延迟。
*   **防限流机制**：
    *   内置 **429 自动重试** 系统，采用指数退避算法。
    *   强制最小间隔保护（1.5秒），避免瞬间高频请求导致 IP 被封。
    *   支持自定义随机延迟范围（例如 5-10秒），模拟真人操作。

### 4. 增强体验
*   **代币支持**：不仅支持 SUI，还支持自定义 CoinType（如 USDC, CETUS 等），自动识别代币精度和符号。
*   **私钥兼容**：支持多种格式导入：
    *   Bech32 (`suiprivkey1...`)
    *   Hex (64字符或32字符)
    *   Base64
*   **详细日志**：
    *   实时显示发送状态、金额、交易 Hash。
    *   交易 Hash 直连 SuiScan 浏览器。
    *   支持一键导出 CSV 格式日志。

## 🚀 快速开始

1.  **下载/安装**：无需安装，直接下载本项目文件夹。
2.  **运行**：双击打开 `index.html` 文件（推荐使用 Chrome 或 Edge 浏览器）。
3.  **配置**：
    *   选择网络节点（推荐使用默认的 Chainstack 节点）。
    *   (可选) 输入代币合约地址，如果留空则默认转账 SUI。
4.  **导入数据**：
    *   根据需求选择功能标签页。
    *   粘贴私钥和接收地址。
    *   点击“确认导入”查看余额。
5.  **执行**：
    *   设置转账金额模式。
    *   (可选) 设置随机延迟。
    *   点击“开始执行”。

## ⚙️ 技术细节

*   **框架**：原生 HTML5 + TailwindCSS (CDN)。
*   **SDK**：通过 ESM 引入 `@mysten/sui.js` (v0.54.1)。
*   **样式**：深色模式设计，保护视力。

## ⚠️ 注意事项

*   **Gas 费**：SUI 网络 Gas 费通常很低，但批量操作时请确保账户内预留了少量 SUI（建议至少保留 0.01 SUI）作为手续费，否则会导致转账失败（尤其是代币转账时）。
*   **测试**：在大额批量操作前，强烈建议先用小额资金进行测试，确保流程无误。
